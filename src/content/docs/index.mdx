XZSV is a small suite of source-shipped Svelte 5 packages for single-page apps that want to _feel_ like games: screens instead of pages, honest loading screens instead of spinner soup, and layouts that never flicker.

- **[@xzsv/router](/guides/router-transitions/)** renders a route as a component tree and navigates by swapping trees. It knows which parts of the page are shared, keeps both trees mounted during a transition, and lets you animate only what changed — with plain CSS.
- **[@xzsv/load](/guides/load/)** folds every wait your first frame depends on — images, fonts, requests, anything — into one percentage and one ready flag. Content loads underneath a loading screen instead of behind an `{#if}`.
- **[@xzsv/animate](/guides/animate/)** packages the transition presets these packages use — `settle`, `reduced`, and the `crossfade` / `slide` / `lift` / `scale` pairs — with [anime.js](https://animejs.com) as an optional peer. The router itself ships zero animation code.
- **[@xzsv/bar](/guides/bar/)** (in testing) is a persistent HUD bar whose contents morph with route changes, inside the router's own transition batch.

Everything is **source-shipped**: the npm package is raw TypeScript with runes and `.svelte` files inside, compiled by your own Svelte setup. One version of reactivity, no build step inside the packages, debuggable in place.
